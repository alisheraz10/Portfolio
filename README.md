## About

This portfolio demonstrates my capabilities as a Full-Stack Developer with a focus on modern web technologies and interactive 3D experiences using **React, TypeScript, and Three.js (R3F)**.  
It includes dynamic components such as:

- Interactive chatbot assistant
- 3D hero sections and animations
- Smooth scroll and responsive UI
- Contact form integration

---

## Features

- **3D WebGL/Three.js Components:** Eye-catching interactive visuals in the hero and other sections.  
- **Dynamic Chatbot Assistant:** A TypeScript-powered AI demo bot integrated into the website.  
- **Responsive Design:** Optimized for mobile, tablet, and desktop.  
- **Dark & Light Theme Support:** Theme switching for user comfort.  
- **Smooth Animations:** Framer Motion used for micro-interactions and transitions.  
- **Production-Ready Setup:** Configured with ESLint, Prettier, and TypeScript for maintainable, clean code.

---

## Tech Stack

- **Frontend:** React, TypeScript, TailwindCSS, Framer Motion  
- **3D & Animations:** Three.js, React Three Fiber (R3F), Drei  
- **Tools & Utilities:** ESLint, Prettier, Vercel deployment  
- **Icons:** Lucide React  
- **Hosting & Deployment:** Vercel
